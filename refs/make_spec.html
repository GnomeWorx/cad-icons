⚙️ Print Preparation Tools

3.1 Manufacturing Model Creation

The derive workflow manages model changes specifically for print preparation, creating Manufacturing Models that separate print-specific modifications from the original design. This non-destructive workflow enables part modifications optimized for 3D printing without altering source geometry, and management of design iterations across print preparation phases.

3.2 Additive Setup

Creating an additive setup is the first step in preparing a model for 3D printing.

ComponentFunction
Machine SelectionChoose from printer library or configure custom machine
Print SettingsDefine layer height, extrusion width, temperature parameters
Material SelectionSpecify material type and properties

🎯 Part Positioning & Orientation

4.1 Manual Positioning

Interactive tools for manually positioning components on the build platform: translation and rotation controls, snap-to-platform functionality, collision detection during placement.

4.2 Automatic Orientation

Algorithm-driven orientation optimization based on minimizing build height, reducing support requirements, optimizing surface quality for critical features, and avoiding overhangs exceeding machine capabilities.

4.3 Automatic Arrangement

Multi-part packing algorithms that automatically arrange multiple components on build platform, maximize build volume utilization, maintain minimum part spacing requirements, and respect machine-specific build area constraints.

🔪 Toolpath Generation Slicing

6.1 Additive Toolpath Generation

The core slicing functionality converts 3D models into printable layers. After proper orientation, arrangement, and support configuration, the additive toolpath is generated with a single click.

CategoryParameters

Perimeter/ShellWall count, outer wall order
InfillPattern type, density, overlap percentage
TemperatureNozzle temperature, bed temperature, cooling

6.3 Print Statistics

The toolpath generation process provides: estimated print time, material consumption (length and weight), energy consumption estimates, and cost calculations (when material costs configured).

🎬 Simulation Tools

7.1 Additive Toolpath Simulation

Simulate the printing process to detect and remedy common print failures.

FeatureDescription
Toolpath SimulationVisualize nozzle/tool movement throughout print
Layer ProgressionWatch build grow layer by layer
Collision DetectionIdentify collisions between tool and part
Extrusion VerificationConfirm material deposition matches expected

7.2 Metal Powder Bed Fusion Simulation

For MPBF processes: thermal simulation (predict heat distribution), stress simulation (identify potential warping and delamination), and compensation (apply geometry compensation for predictable distortion).

Extension Required: MPBF simulation requires additional licensing beyond base FissionCAD.

📤 Export & Post-Processing

8.1 G-Code Generation

1. Click Post Process button in SIMULATE ADDITIVE TOOLPATH dialog
2. NC Program dialog opens automatically
3. Select appropriate post-processor for target machine
4. Configure post-processor properties
5. Generate and save G-code file
