Plastic Modeling Tools Specification

FissionCAD — Fusion 360 Solid Modeling (Plastic) tools, inspired by the Product Design Extension

Note: The plastic-specific tools documented here are inspired by Fusion 360's Product Design Extension — a paid add-on. FissionCAD implements equivalents where possible. Base modeling (Extrude, Shell, Draft, Fillet) is available without restrictions.

📋 Plastic Rules Intelligent Material Definition

Plastic Rules are parametric definitions that control material properties and manufacturing constraints across components. They enable automatic propagation of design parameters whenever a feature is created.

3.1 Rule Components

CategoryParametersFunction
Physical MaterialMaterial type (ABS, Nylon, etc.)Affects mass/physical properties
Physical ValuesThickness, Draft Angle, Nominal RadiusReferenced by modeling commands
Design Advice ValuesThickness range, variation, min draft angle, knife-edge thresholdUsed for manufacturability analysis

3.2 How Rules Apply to Features

FeatureInherits From Rule
ShellThickness
Rib/WebThickness, Draft Angle
BossDraft Angle, Thickness
Snap FitThickness, Draft Angle
DraftDraft Angle
FilletNominal Radius

3.3 Workflow

1. Access Plastic Tab → Assign Plastic Rule
2. Select target component
3. Choose pre-defined rule or create custom
4. Rule populates Parameters dialog automatically
5. Subsequent features inherit rule values
6. Change material → all features update automatically

🏭 Plastic Feature Tools

4.1 Boss Tool

Creates cylindrical protrusions (bosses) for fastener attachment and component joining.

ParameterDescription
PositioningRequires sketch point (recommended on offset or mid-plane)
Offset PositionDistance from sketch plane
DiameterBoss outer diameter
Fastener DiameterInner hole diameter for screw/insert
DirectionBoss extrusion direction
Dual BossesCreates bosses on both sides of sketch plane when two bodies visible
Rule Integration: Boss automatically applies Draft Angle and Thickness from assigned Plastic Rule.

4.2 Snap Fit Tool

Creates snap-fit geometry for joining two plastic components without fasteners.

TypeDescription
Parallel Hook & GrooveHook and groove aligned with pull direction
Perpendicular Hook & GrooveHook perpendicular to pull direction
Hook & LoopCantilever hook with catching loop
Parameters: Position via sketch points between two bodies, individual or global hook angle adjustment, hook extension/shortening controls, automatic clearance cut when hook intersects second body.
Rule Integration: Inherits Thickness and Draft Angle from Plastic Rule.

4.3 Rib / Web Tool

Creates reinforcing ribs or webs to strengthen thin-walled plastic parts without increasing overall thickness.

Rule Integration: Thickness driven by Plastic Rule, Draft Angle applied automatically, associative top/bottom features created.

4.4 Shell Tool

Converts a solid body into a hollow shell with uniform wall thickness.

Rule Integration: Thickness automatically populates from Plastic Rule when rule is assigned. Must assign Plastic Rule before using Shell for inheritance to work.

4.5 Draft Tool

Applies draft angles to faces to enable ejection from injection molds.

Rule Integration: Draft Angle value inherits from Plastic Rule. Pull direction must be defined for Design Advice analysis.

4.6 Thicken Tool

Adds thickness to surface bodies or offsets faces of solid bodies.

Rule Integration: Thickness value inherits from assigned Plastic Rule. Requires rule assignment prior to feature creation.

4.7 Geometric Pattern Tool

Creates complex patterns on flat or curved surfaces with size gradients and multiple distribution types.

DistributionDescription
SquareGrid arrangement
TriangularStaggered triangular layout
HexagonalHoneycomb pattern
CircularRadial arrangement around center
ArrayedStandard array pattern
Shape Options: Default shapes (Sphere, Cylinder, Cube) or custom shape (any solid body in file).
Key Parameters: Size limit/range (varies object sizes), border clearance option, face selection, join/cut/new body boolean operations.
Applications: Ventilation holes, grip textures, aesthetic patterns, light passages.

🔬 Analysis & Validation Tools

5.1 Design Advice

Identifies manufacturability concerns based on injection molding best practices and assigned Plastic Rules.

1. Select Design Advice in Plastic tab
2. Select component and pull direction (tool movement direction after injection)
3. Click Analyze
TabIssues Checked
ThicknessLarge variations, walls too thin, walls too thick
UndercutsFeatures requiring sliders or lifters in mold
DraftFaces with insufficient draft angle
Knife-edgeThin, long tool features (causes premature wear)

5.2 Snap Design Analysis

Analyzes snap performance including deformation during engagement.

5.3 Volumetric Lattice

Modifies existing solid or mesh bodies to create complex internal lattice structures.
Parameters: Cell shape, cell size, density.

📋 Recommended Workflow

1. Activate Product Design Extension
2. Access Plastic Tab in Design Workspace
3. Assign Plastic Rule to component(s)
   └── Select material (ABS, Nylon, etc.)
   └── Define/confirm physical values
   └── Set design advice thresholds
4. Create base geometry (Extrude, Revolve, etc.)
5. Apply Shell (inherits thickness from rule)
6. Add plastic features:
   ├── Boss (from sketch points)
   ├── Snap Fits (from sketch points)
   └── Ribs/Webs
7. Apply automatic Draft and Fillet (rule-driven)
8. Run Design Advice analysis
   └── Define pull direction
   └── Review thickness/undercut/draft/knife-edge alerts
   └── Implement recommendations
9. Iterate and refine
