🔒 Constraint Tools Geometric Relationships

Constraints enforce geometric relationships between sketch entities. These are rules — not dimensions — that control how geometry relates.
ConstraintIconFunction
Coincident●Forces two points to share the same location
Horizontal↔Forces line to be exactly horizontal
Vertical↕Forces line to be exactly vertical
Parallel∥Forces two lines to run in same direction
Perpendicular⟂Forces two lines to meet at 90°
Tangent○—Forces curve to touch another curve smoothly at one point
Equal≡Forces lengths or radii to be identical
Concentric◎Forces circles/arcs to share center point
Collinear—Forces lines to lie on same infinite line
Fix📌Locks entity position
Midpoint◇Forces point to midpoint of line
Symmetric⇄Forces symmetry across centerline
Curvature()Maintains curvature continuity between splines (G2)
Constraint Status Colors:
Black = Fully constrained
Blue = Under-constrained (free to move)

📏 Dimension Tools Parametric Constraints

Dimensions control exact size values and are parametric — they can be edited and drive model updates.
Dimension TypeFunctionParameters
Distance DimensionLinear distance between two points or line lengthValue (mm), text position
Radius DimensionRadius of arc or filletValue (mm)
Diameter DimensionDiameter of circleValue (mm)
Angle DimensionAngle between two linesValue (degrees)
Best Practices:
• Name dimensions descriptively (e.g., hole_offset = 0.1 * width)
• Use expressions to create relationships between parameters
• Fully constrain sketches for predictable updates
Shortcut Key: D = Dimension

📐 Construction & Reference Tools

ToolFunctionVisual Indicator
Construction GeometryCreates reference geometry that doesn't form profilesDashed/dotted lines
CenterlineCreates axis geometry that participates in profilesDot-dash lines
ProjectProjects 3D edges/faces onto current sketch planeProjected geometry
Project Cut EdgesProjects intersection of plane with existing bodiesIntersection curves
Construction vs. Centerline:
• Construction: Purely reference — does not affect profiles
• Centerline: Acts as profile boundary, used for symmetry and revolve axes

📋 Workflow Summary

1. Create Sketch → Select Plane
2. Create Geometry (Lines, Circles, etc.)
3. Apply Constraints (Horizontal, Parallel, Tangent, etc.)
4. Add Dimensions (Distance, Radius, Angle)
5. Modify as Needed (Trim, Offset, Fillet, Pattern)
6. Verify Geometry (Blue = Under-defined → Black = Fully defined)
7. Finish Sketch
8. Create 3D Feature (Extrude, Revolve, etc.)
