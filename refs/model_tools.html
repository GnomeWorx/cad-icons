Specification: Fusion 360 Solid Modeling (Plastic) Tools

1. Overview

Fusion 360's plastic part design tools are primarily available through the Product Design Extension—a paid add-on that extends core modeling capabilities with manufacturing-aware features. These tools automate the creation of common plastic features like bosses, snap fits, and ribs, while enforcing design rules based on injection molding best practices.

Extension Requirement: The plastic-specific tools documented below require the Product Design Extension. Base Fusion 360 includes standard solid modeling tools (Extrude, Shell, Draft, Fillet) but lacks the automated, rule-driven plastic features.

3. Plastic Rules (Intelligent Material Definition)

Plastic Rules are parametric definitions that control material properties and manufacturing constraints across components. They enable automatic propagation of design parameters whenever a feature is created.

3.1 Rule Components

RefRef CategoryParametersFunction
MD-004 MD-004 Physical MaterialMaterial type (ABS, Nylon, etc.)Affects mass/physical properties
MD-005 MD-005 Physical ValuesThickness, Draft Angle, Nominal RadiusReferenced by modeling commands
MD-006 MD-006 Design Advice ValuesThickness range, Thickness variation, Minimum draft angle, Knife-edge thresholdUsed for manufacturability analysis

3.3 Workflow



1. Access Plastic Tab → Assign Plastic Rule


2. Select target component


3. Choose pre-defined rule or create custom


4. Rule populates Parameters dialog automatically


5. Subsequent features inherit rule values


6. Change material → all features update automatically





3.4 Pre-set Rules



Fusion 360 includes pre-populated plastic rules for common materials that can be customized or used as-is.






4. Plastic Feature Tools



4.1 Boss Tool



Creates cylindrical protrusions (bosses) for fastener attachment and component joining.



Fastener Integration:
  • Select from library of fasteners (standards-based)
  • Configure: Head Type, Drive, Length, Thread Angle, Diameter, Material, Surface Finish
  • Fastener added as new component to file
    • Rule Integration: Boss automatically applies Draft Angle and Thickness from assigned Plastic Rule.

    5. Analysis & Validation Tools
    


    5.1 Design Advice (Preview)
    


    Identifies manufacturability concerns based on injection molding best practices and assigned Plastic Rules.
    


    Workflow:
    

    

    1. Select Design Advice in Plastic tab
    

    2. Select component and pull direction (tool movement direction after injection)
    

    3. Click Analyze
    

    


    Analysis Categories:
    


    Recommendations:
  • Each alert includes actionable recommendations
  • Links to in-depth concepts for learning
  • Option to ignore specific regions after addressing
    • Rule Integration: Uses Thickness Range, Thickness Variation, Minimum Draft Angle, and Knife-edge Threshold from assigned Plastic Rule.
    

    RefRef  TabIssues Checked
    


    MD-027  MD-027  ThicknessLarge variations, walls too thin, walls too thick
    

    MD-028  MD-028  UndercutsFeatures requiring sliders or lifters in mold
    

    MD-029  MD-029  DraftFaces with insufficient draft angle
    

    MD-030  MD-030  Knife-edgeThin, long tool features (causes premature wear)

    9. Recommended Workflow
    


    

    1. Activate Product Design Extension
    

    2. Access Plastic Tab in Design Workspace
    

    3. Assign Plastic Rule to component(s)
    

       └── Select material (ABS, Nylon, etc.)
    

       └── Define/confirm physical values
    

       └── Set design advice thresholds
    

    4. Create base geometry (Extrude, Revolve, etc.)
    

    5. Apply Shell (inherits thickness from rule)
    

    6. Add plastic features:
    

       ├── Boss (from sketch points)
    

       ├── Snap Fits (from sketch points)
    

       └── Ribs/Webs
    

    7. Apply automatic Draft and Fillet (rule-driven)
    

    8. Run Design Advice analysis
    

       └── Define pull direction
    

       └── Review thickness/undercut/draft/knife-edge alerts
    

       └── Implement recommendations
    

    9. Iterate and refine
    

    10. (Optional) Run mold filling simulation with Simulation Extension
