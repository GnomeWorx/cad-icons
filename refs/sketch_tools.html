Specification: Fusion 360 Sketch Tools

1. Overview

The Fusion 360 Sketch environment provides tools for creating and editing 2D geometry that serves as the foundation for 3D features. This specification documents all primary sketch tools organized by functional category.

2. Sketch Creation & Environment Setup

Environment Notes :

  • Blue geometry = Under-defined (missing constraints/dimensions)
  • Black geometry = Fully defined
  • Use S key to open shortcut menu for quick tool access
    • RefToolFunctionActivation
    SK-001 Create SketchCreates a new 2D sketch on a selected plane or faceToolbar → Create Sketch or right-click → Create Sketch
    SK-002 Finish SketchExits sketch environment and saves changesToolbar → Finish Sketch

    6. Constraint Tools (Geometric Relationships)

    Constraints enforce geometric relationships between sketch entities . These are rules—not dimensions—that control how geometry relates.

    Constraint Status Colors :

  • Black = Fully constrained
  • Blue = Under-constrained (free to move)
    • RefConstraintIconFunction
    SK-025 Coincident●Forces two points to share the same location
    SK-026 Horizontal↔Forces line to be exactly horizontal
    SK-027 Vertical↕Forces line to be exactly vertical
    SK-028 Parallel∥Forces two lines to run in same direction
    SK-029 Perpendicular⟂Forces two lines to meet at 90°
    SK-030 Tangent○—Forces curve to touch another curve smoothly at one point
    SK-031 Equal≡Forces lengths or radii to be identical
    SK-032 Concentric◎Forces circles/arcs to share center point
    SK-033 Collinear—Forces lines to lie on same infinite line
    SK-034 Fix📌Locks entity position
    SK-035 Midpoint◇Forces point to midpoint of line
    SK-036 Symmetric⇄Forces symmetry across centerline
    SK-037 Curvature()Maintains curvature continuity between splines (G2)

    7. Dimension Tools (Parametric Constraints)

    Dimensions control exact size values and are parametric—they can be edited and drive model updates .

    Best Practices :

  • Name dimensions descriptively (e.g., hole_offset = 0.1 * width)
  • Use expressions to create relationships between parameters
  • Fully constrain sketches for predictable updates

    • Shortcut Key :

  • D = Dimension
    • RefDimension TypeFunctionParameters
    SK-038 Distance DimensionLinear distance between two points or line lengthValue (mm), text position
    SK-039 Radius DimensionRadius of arc or filletValue (mm)
    SK-040 Diameter DimensionDiameter of circleValue (mm)
    SK-041 Angle DimensionAngle between two linesValue (degrees)

    8. Construction & Reference Tools

    Construction vs. Centerline :

  • Construction: Purely reference—does not affect profiles
  • Centerline: Acts as profile boundary, used for symmetry and revolve axes
    • RefToolFunctionVisual Indicator

    SK-043 CenterlineCreates axis geometry that participates in profilesDot-dash lines
    SK-044 ProjectProjects 3D edges/faces onto current sketch planeProjected geometry
    SK-045 Project Cut EdgesProjects intersection of plane with existing bodiesIntersection curves

    10. Workflow Summary

    

    1. Create Sketch → Select Plane
    

    2. Create Geometry (Lines, Circles, etc.)
    

    3. Apply Constraints (Horizontal, Parallel, Tangent, etc.)
    

    4. Add Dimensions (Distance, Radius, Angle)
    

    5. Modify as Needed (Trim, Offset, Fillet, Pattern)
    

    6. Verify Geometry (Blue = Under-defined → Black = Fully defined)
    

    7. Finish Sketch
    

    8. Create 3D Feature (Extrude, Revolve, etc.)
